Stage 1 — Data Collection

Every domain scan runs 9 independent async probes. Here is exactly how each one works.

Probe 1&2 — TLS 1.2 and TLS 1.3 Cipher Enumeration

Python ssl.SSLContext with version locked:

context.minimum_version = ssl.TLSVersion.TLSv1_3
context.maximum_version = ssl.TLSVersion.TLSv1_3
ssl_sock = context.wrap_socket(sock, server_hostname=domain)
# wrap_socket() performs the full TLS handshake
negotiated = ssl_sock.cipher()  # what server chose

TLS 1.3 ciphers confirmed via:
openssl s_client -tls1_3 -ciphersuites TLS_AES_256_GCM_SHA384 ...

Probe 3 — Full Certificate Chain

echo Q | openssl s_client -showcerts \
  -servername <domain> -connect <ip>:443

Each PEM block → x509.load_pem_x509_certificate() → DER bytes.

Probe 4 — Classical Named Groups

echo Q | openssl s_client -groups X25519 \
  -connect <ip>:443 -servername <domain> 2>&1
# "handshake failure" NOT in output → curve supported

Candidates: X25519, secp256r1, secp384r1, X448, secp521r1, ffdhe2048, ffdhe3072, ffdhe4096

Probe 5 — PQ Hybrid Groups (OpenSSL 3.5 required)

echo Q | openssl s_client -groups X25519MLKEM768 \
  -connect <ip>:443 -servername <domain> 2>&1

⚠️ Simple handshake success = false positive!

if "negotiated tls1.3 group: x25519mlkem768"
    in output.lower():
    supported.append(group)

Probe 6 — Legacy Protocol Detection (TLS 1.0/1.1)

echo Q | openssl s_client -tls1 \
  -cipher 'DEFAULT:@SECLEVEL=0' \
  -connect <ip>:443 -servername <domain> 2>&1

Python 3.10+ removed TLS 1.0/1.1 — must use CLI.
@SECLEVEL=0 needed on OpenSSL 3.x.

Probes 7, 8, 9 — DHE Key Size, OCSP, Cipher Preference

# DHE Key Size (Logjam detection):
openssl s_client -tls1_2 -cipher 'DHE-RSA-...' ...
# "Peer Temp Key: DH, 1024 bits" → key_size=1024
# OCSP Stapling:
openssl s_client -status -connect <ip>:443 ...
# "OCSP Response Status: successful" → True

Stage 2 — Normalization

Raw probe outputs converted into a single typed JSON object via normalize_endpoint_data()

Cipher Suite Parsing (cipher_parser.py)

Branch on prefix: TLS_ → TLS 1.3 path, else → TLS 1.2 path

# TLS 1.3 — token scan
Input:  "TLS_AES_256_GCM_SHA384"
"AES"+"256"+"GCM" → symmetric = "AES-256-GCM"
"SHA384"          → hash = "SHA384"
kex hardcoded     → "ECDHE"

# TLS 1.2 — left-to-right token parse
Input:  "ECDHE-RSA-AES256-GCM-SHA384"
starts("ECDHE")   → kex = "ECDHE"
next("RSA")       → auth = "RSA"
"AES256"+"GCM"    → symmetric = "AES-256-GCM"
"SHA384"          → hash = "SHA384"

# No prefix = static RSA
Input:  "AES256-GCM-SHA384"
no prefix         → kex = "RSA" (default)

Certificate Chain Parsing (certs.py)

cert = x509.load_der_x509_certificate(der_bytes, default_backend())
subject    = cert.subject.rfc4514_string()
issuer     = cert.issuer.rfc4514_string()
valid_from = cert.not_valid_before_utc.isoformat()
key_size   = cert.public_key().key_size   # bits
sig_algo   = cert.signature_algorithm_oid._name

PQ-First Ordering Rule

Critical for scoring: PQ hybrid groups must be placed at position 0. The scoring engine applies position decay — position 5 yields only 80% of the score vs. position 0. 
# Merge rule in normalize_endpoint_data:
for cname in subprocess_curves:
    if any(tok in cname.upper()
           for tok in {"MLKEM","KYBER"}):
        pq_prefix.append(entry)
    else:
        classical_suffix.append(entry)

# Final order: PQ → classical → inferred
supported_curves = pq_prefix + classical_suffix + supported_curves

DHE Injection

dh_bits = raw_data.get("dh_key_size")  # e.g. 1024
if dh_bits:
    dh_name = f"DHE-{dh_bits}"   # "DHE-1024"
    supported_curves = [{"name": dh_name,
                          "bits": dh_bits}] + supported_curves
# Scores: base(DHE=5) + key_bonus(-30) = clamped to 0
# → Logjam correctly detected

6 sequential steps in extract_algorithms_from_tls_scan() convert normalized JSON → flat algorithm list for the scorer

StepSource FieldType AssignedLogic
1supported_elliptic_curves.curveskexAll named groups in server-preference order. position = index. PQ hybrid groups are already at position 0.
2tls_1.3_cipher_suites[*].encryptionsymmetricTLS 1.3 AEAD suites only. Deduplicated.
3tls_1.2_cipher_suites[*].encryptionsymmetricTLS 1.2 encryption fields. Skip NULL/Unknown. Don't re-add if already in step 2.
4tls_1.2_cipher_suites[*].key_exchangekexOnly non-ECDHE entries (DHE, FFDHE, RSA static). ECDHE is already in the named groups from step 1.
5signature_algorithms.certificate_signaturessignatureOne entry per distinct signature algorithm in the certificate chain.
6supported_protocolsprotocolOne entry per supported protocol string: TLS 1.3, TLS 1.2, TLS 1.1, etc.

Stage 4 — PQC Scoring Engine

Stateless service in universal-scoring-service/core/scorer.py — receives algorithm list, returns grades

Per-Algorithm Score Formula

base_score = PQ_RESISTANCE_TABLE[type][name] OR fuzzy longest-substring match key_size_bonus: symmetric ≥ 256 bits → +10 symmetric = 128 bits → 0 RSA/DH ≥ 4096 bits → +10 RSA/DH = 2048 bits → 0 RSA/DH < 2048 bits → -30 curve_bonus: X25519 / X448 / Ed25519 → +15 P-521 → +10 P-384 → +5 P-256 → 0 P-224 → -10 final_score = clamp(base + key_bonus + curve_bonus, 0, 100) weighted = final_score × (1 / (1 + 0.05 × position))

Position Decay — Why Position Matters

Component Aggregation

KEX Special Rule (85/15 split):
If any KEX algorithm is a PQ hybrid:
kex_score = 0.85 × PQC_avg + 0.15 × classical_avg

The 4-Stage Overall Score Formula

After component scores are computed, _calculate_overall_score() applies four sequential adjustments

Stage 1 — Base

base = Σ(comp × weight) / Σ(weights)

Weighted average of all component scores using the 40/25/20/10/5 weights.

Stage 2 — Hybrid Bonus

if hybrid_ready: best ≥ 97 → +18 pts best ≥ 92 → +15 pts best ≥ 85 → +12 pts any hybrid → +8 pts sym < 65 → -5 pts

Stage 3 — Floor

if hybrid_ready AND sym ≥ 70: score = max(score, 55)

Prevents correctly deployed PQ hybrid sites from falling below grade C.

Stage 4 — Protocol Adj.

TLS 1.3 + no hybrid: +7 pts Legacy TLS 1.0/1.1: −(50 − proto) × 0.2 (max −10 pts)

Quantum Readiness & HNDL Risk

HNDL Threat

Harvest Now, Decrypt Later. An adversary records TLS-encrypted traffic today and stores it. When a large quantum computer exists, they decrypt it retroactively.

This threat is active today. Nation-state actors are known to be harvesting traffic. Data encrypted with ECDHE/RSA has zero protection against future quantum decryption.

Quantum Algorithms

Shor's Algorithm breaks RSA and all Elliptic Curve cryptography in polynomial time on a quantum computer.

Grover's Algorithm provides quadratic speedup against symmetric-key search:

AES-256128-bit quantum security ✓
AES-12864-bit quantum security ⚠️

Our Flags

hybrid_ready = any KEX is PQ hybrid (X25519MLKEM768 present) quantum_ready = hybrid_ready AND sym_score ≥ 70 Note: PQC certs NOT required. CAs can't issue ML-DSA yet. (est. 2026–2028)

HNDL Risk: LOW

Hybrid PQC KEX deployed. Traffic protected against quantum HNDL today.

HNDL Risk: MEDIUM

X25519 or ECDHE only. Classically secure, but all recorded traffic is retroactively vulnerable.

HNDL Risk: HIGH

RSA KEX or DHE < 2048 bits. Critically vulnerable classically and to quantum attacks.

Migration Tier 1

hybrid_ready + sym≥70
KEX migration complete. Await ML-DSA certs from CAs (~2026–2028).

Migration Tier 2

hybrid_ready but weak symmetric. Deploy AES-256-GCM / ChaCha20-Poly1305.

Migration Tier 3

Not hybrid ready. Deploy X25519MLKEM768 immediately. Disable TLS 1.0/1.1.

Scoring Calculation

KEX:
  X25519MLKEM768  base=97, +curve=+15 → 100, pos=0 → 100.0
  X25519MLKEM1024 base=98, +curve=+15 → 100, pos=1 →  95.2
  X25519          base=15, +curve=+15 →  30, pos=2 →  27.3
  secp256r1       base=10, curve=  0  →  10, pos=3 →   8.7
  hybrid_ready = TRUE
  PQC avg  = (100.0+95.2)/2  = 97.6
  class avg= (27.3+8.7)/2    = 18.0
  kex = 0.85×97.6 + 0.15×18.0  = 85.7

SYMMETRIC: AES-256-GCM(100) + ChaCha20(83.8) + AES-128(68.2)
  sym = weighted avg          = 89.0

SIGNATURE: ecdsa-with-SHA256  = 35.0 (classical only)

PROTOCOL: TLS 1.3(90) + TLS 1.2(71.4) = 82.5

Stage 1: (85.7×0.40 + 89.0×0.25 + 35.0×0.20 + 82.5×0.10) / 0.95
       = (34.28+22.25+7.00+8.25) / 0.95 = 75.6

Stage 2: best PQC=100 ≥ 97 → +18 pts
       = 75.6 + 18 = 93.6

FINAL = min(93.6, 100) = 91.2 → A+
